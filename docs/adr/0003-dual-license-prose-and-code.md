# Dual-license: CC-BY prose, CC0 example code

LuaDocs licenses its own **rewritten prose (Reference + Guides) under CC-BY 4.0**
and its **example code under CC0 (public domain)**. This is separate from the
per-entry **source link** crediting the original Lua manual, which appears
regardless of license.

## Why

A single license forces a bad trade-off. One attribution license for everything
would burden readers who copy a two-line example with a legal credit obligation —
friction against the goal of people actually using Lua. One no-attribution
license for everything would surrender credit on the prose, the site's main
creative work. Splitting optimizes each: prose is credited, examples are
friction-free to reuse. This mirrors MDN (prose CC-BY-SA, code CC0).

## Consequences

- A short LICENSE file and site footer must state both licenses and the boundary
  between prose and code.
- A content license is hard to reverse once outside contributors add work, so the
  license is fixed early and contribution terms must reflect it.

---
title: LuaDocs Reference
description: An MDN-style reference for the Lua language.
---

The Reference is a lookup-oriented rewrite of the official Lua manual: one entry
per function, operator, or language construct, each tagged with the Lua
versions it applies to.

It covers Lua 5.1 through 5.5. Use the version switcher in the header to change
which version an entry describes — it updates the version support strip, any
change notes, and which examples run.

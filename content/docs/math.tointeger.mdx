---
title: math.tointeger
description: Convert a value to an integer, or nil if it has no integer representation.
lua-compat: math.tointeger
---

Returns the value converted to an integer. If the value has no exact integer
representation, it returns `nil` instead.

<RunnableExample code={`print(math.tointeger(3.0))\nprint(math.tointeger(3.5))`} />

This entry exists to exercise version-scoped availability: it is absent from the
earlier Lua lines, so selecting one of those dims it in the sidebar and replaces the
change note with an availability note.
